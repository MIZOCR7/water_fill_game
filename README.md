# water_fill_game
Nearly all of us has this game on our phones but who thinks to build it for computer, simply it was me :), really this game is so nice and I like it I spend a lot of time playing and getting to harder levels on my phone so why not to make a simple version on the laptop, the game is about collecting all colored water in tubes same colors with each other.

# How to play
Just download the .exe file from releases and have fun

# What I learnt 
simply nothing it was an easy project I made nearly in 6 hours most of them in thinking and just 2 hours of coding hope U add those hours :)

# controllers
Just play and click with Ur mouse, and use Space to return tubes as they was first if U are stuck and Enter (Return) to randomize all things
